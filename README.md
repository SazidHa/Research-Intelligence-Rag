# Research Intelligence RAG

A production-style Retrieval-Augmented Generation platform for scientific and technical research documents.

## Project Goals

This project explores and implements:

- Document ingestion and preprocessing
- Semantic vector retrieval
- Hybrid dense and sparse retrieval
- Query rewriting
- Reranking
- Metadata filtering
- RAG evaluation
- Agentic corrective RAG
- Graph RAG
- Multimodal document understanding
- FastAPI backend
- Next.js frontend
- Docker deployment
- Azure cloud deployment
